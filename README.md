# 取件助手 QuJian

一个自用性质的 Android 小工具，把「看通知 → 找取件码 → 打开身份码」压缩到一起。


---

## 下载与安装

前往本仓库的 **Releases** 页面，下载 `v1.0.0` 中的 APK 附件，在手机上打开安装即可。

| 项目 | 值 |
|---|---|
| 当前版本 | `v1.0.0`（终版） |
| 应用版本 | `0.1.0`（versionCode `1`） |
| 包名 | `com.qujian.pickup2` |
| 最低系统 | Android 7.0（API 24） |
| 目标系统 | Android 14（API 34） |
| 体积 | 约 45.4 MB |

安装前请注意：

- 系统可能提示「未知来源应用」或「该安装包未经验证」——因为使用调试签名且未上架应用商店，属正常现象。
- 校验值见 Releases 页 v1.0.0 说明。

## 功能

| 功能 | 说明 |
|---|---|
| 一键身份码 | 主页按钮、桌面小组件、长按应用图标三种入口，直达拼多多 / 淘宝的取件身份码页 |
| 通知自动收录 | 监听通知栏中含取件码的快递通知，自动解析入库；同一码自动去重 |
| 图片识别取件码 | 相册选图 / 拍照 / 从其他 App 分享图片，离线中文 OCR 识别后确认入库；支持一图多码、逐条编辑 |
| 取件码列表 | 大字显示取件码，附驿站、快递公司；点击卡片即复制 |
| 搜索与分组 | 按取件码 / 驿站 / 快递公司 实时过滤，可切换按驿站分组 |
| 侧滑操作 | 左滑露出删除按钮并停住，右滑收起 |

## 首次使用需要开启的权限

1. **通知使用权**：主页顶部有状态提示与一键跳转系统设置。开启后才会自动收录取件码。
   App 只读取通知栏文本，不读取短信数据库，也不按固定 App 包名过滤。
2. **无障碍服务**（可选）：用于身份码页的自动点击与广告弹窗关闭。主页同样提供设置入口与状态提示。

两个权限都只在本机使用，可在系统设置中随时关闭。

---

## 隐私与数据处理

- 取件码数据**只保存在本机**，没有账号体系，不上传服务器。
- 图片识别使用打包进 APK 的离线中文 OCR 模型，全过程不联网、。
- 不申请短信读取、通讯录、位置等无关权限；相册选图走系统文件选择器，拍照走应用内 FileProvider。
- 身份码跳转仅调用对应电商 App 的公开页面地址；目标 App 未安装或地址失效时回退为「只打开该 App」。
